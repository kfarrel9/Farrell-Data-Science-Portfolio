# Palmers Penguins Explorer

## About This Streamlit App
This app allows users to better understand the differences between various penguin species: Adelie, Chinstrap, and Gentoo

Users can interact with different features in each species tab, including filters, summary statistics, graphs, maps, and fun facts.

## Features

- Explore Adelie, Chinstrap, and Gentoo penguins in separate tabs
- Filter penguins using interactive Streamlit widgets
- View summary statistics for each species
- Explore different visualizations, including scatterplots, boxplots, and maps
- Learn fun facts about each penguin species

## Data

The app uses the Palmer Penguins dataset, which includes information such as species, island, sex, body mass, bill measurements, and flipper length.

## How to Run the App

1. Open the project in VS Code.
2. Make sure Streamlit is installed.
3. Run the following command in the terminal:

streamlit run basic_streamlit_app/main.py
